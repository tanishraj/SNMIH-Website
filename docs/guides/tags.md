# Tags Guide

## What This Section Is

`Tags` stores reusable topical labels used for cross-linking content. In North Valley Medical College, tags can capture specific themes like `MBBS`, `Scholarships`, `Hostel`, or `Faculty Research` that cut across broader categories.

## When To Use It

Use `Tags` when content needs lightweight topical labels that help users and editors connect related pieces across multiple categories.

Do not use it for:

- the main content structure, which belongs in `Topics`
- page URLs or navigation items

## How It Connects To The Website

Tags support Articles, Reviews, and News & Events. Article tag archives are live at `/articles/tag/[slug]`; News & Events can filter Tags through archive query parameters. There is no Review tag archive.

If tags are inconsistent or overly specific, the website becomes cluttered with weak labels that do not help real users.

## Step-By-Step Medical College Example

Create an `MBBS` tag for North Valley Medical College:

1. Open `Tags`.
2. Click `Create New`.
3. Enter the title `MBBS`.
4. Confirm the slug is `mbbs`.
5. Add a short description explaining that this tag is used for MBBS admission, curriculum, and student guidance content.
6. Add SEO fields only if tag pages are intended to matter publicly.
7. Save the tag.

Expected website result:

- editors can attach `MBBS` to Articles, Reviews, and News & Events across multiple Topics
- related article modules can surface MBBS-linked content more intelligently

## Best Practices

- keep tags specific but reusable
- use a controlled vocabulary instead of inventing new labels every week
- prefer singular editorial meaning for each tag
- review existing tags before adding a new one

## Common Mistakes And Recovery

- using tags that duplicate categories exactly
- creating tags that only fit one article
- mixing inconsistent naming like `mbbs`, `MBBS Program`, and `Bachelor of Medicine`

If the tag list becomes messy, standardize on one term and stop using the weaker variants.
