# Admin Dashboard Guide

## What This Section Is

The custom admin dashboard is the operational landing page after sign-in. It summarizes content totals, items needing attention, recent edits, and recent form submissions, and provides shortcuts to common create and management screens.

The dashboard follows the signed-in user's feature grants. Counts, recent records, operational cards,
and quick actions appear only for areas that user can manage. Admins see the full dashboard; Site
Managers see a smaller workspace without inaccessible areas.

The public frontend also shows an authenticated CMS session bar with the current role, a link back to Admin, and logout.

## How To Use It

1. Start with `Reviews awaiting moderation`, `Open Submissions`, and `Action Queue` when those
   features are assigned. An unavailable count is shown explicitly instead of being treated as zero.
2. Use the filtered moderation link to approve or reject submitted Reviews.
3. Use recent edits to resume work on active content.
4. Use quick actions only for collections you are responsible for.
5. Treat Content Overview totals as orientation, not as a replacement for filtered collection
   views or the Audit Log.
