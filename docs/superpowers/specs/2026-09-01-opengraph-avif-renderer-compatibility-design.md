# Open Graph AVIF Renderer Compatibility

## Problem

The shared Open Graph loader fetches the Payload Site Settings logo and converts its bytes into a
data URL while preserving the upstream MIME type. When that logo is AVIF, the generated
`data:image/avif;base64,...` source reaches Next.js 16.2.10 `ImageResponse`. Its bundled Satori
renderer recognizes AVIF but does not produce an intrinsic-size tuple for it, causing the minified
production error `TypeError: u2 is not iterable` while prerendering `/opengraph-image-*`.

The existing tests mock `next/og`, so they verify the JSX contract but never execute the renderer
that fails in production.

## Decision

Normalize fetched AVIF logo bytes to PNG inside `loadOpenGraphRemoteImage` before constructing the
data URL. Use the repository's existing `sharp` dependency and preserve the validated Payload width
and height already carried by `OpenGraphMediaImage`.

PNG, JPEG, GIF, SVG, and WebP responses keep their existing bytes and MIME type. If AVIF decoding or
PNG encoding fails, the loader returns `undefined`, allowing every Open Graph route to use the
existing code-owned fallback image. No exception escapes into prerendering.

## Data Flow

1. An Open Graph route validates the populated Payload logo URL and dimensions.
2. The shared loader fetches the logo with the existing three-second timeout.
3. Successful `image/avif` bytes are decoded and encoded as PNG.
4. The route receives `data:image/png;base64,...` and renders its existing dynamic card.
5. Invalid responses, transport failures, and failed conversion use the existing local fallback.

## Testing

- Extend the helper tests with valid AVIF bytes generated by `sharp` and assert PNG normalization.
- Add a Node-environment integration test that sends the normalized source through the real
  `ImageResponse` and consumes the response body, covering the production renderer rather than a
  mock.
- Keep existing transport, timeout, fallback, and route tests passing.
- Run TypeScript, lint, project-context update/check, and a production build.

## Scope

This change affects only Open Graph logo rendering. It does not alter ordinary `next/image` format
negotiation, media storage, Payload schema, CDN caching, remote host configuration, or the visual
Open Graph layouts.
