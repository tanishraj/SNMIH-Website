# Bank Details Ledger Label Color Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the green accent on the six Bank Details credential terms with the subdued slate foreground used by the fee atlas while preserving the remaining accent hierarchy.

**Architecture:** Keep the change local to `BankDetailsLedger`: stop opting credential terms into the shared green eyebrow surface hook and give them an explicit fixed-white-ledger foreground. Preserve the purpose eyebrow, verification status, schema, values, interactions, and semantic markup.

**Tech Stack:** React 19, TypeScript, Tailwind CSS 4, Vitest, Testing Library.

## Global Constraints

- Change only Account Holder, Account Number, Bank Name, IFSC Code, Branch & Type, and UPI ID term colors.
- Keep `Admissions account` and `Verified` green.
- Preserve the credential terms' current mono family, 0.6875rem size, semibold weight, uppercase treatment, and 0.14em tracking.
- Use `text-light-overlay-foreground/65` because the ledger is fixed white in both website color modes.
- Do not change Payload fields, generated types, the Admin import map, thumbnail fixture, copy behavior, or accessible names.
- Do not stage or commit changes.
