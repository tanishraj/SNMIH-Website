# Fee Structure Programme Cost Atlas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Programme Cost Atlas as a backward-compatible optional layout inside the existing Fee Structure block.

**Architecture:** Extend the existing Fee Structure schema and normalization with Atlas-only programme details and per-category programme-expense content. Keep category-tab state in `FeeStructureClient`, isolate the new 50/50 presentation in its own component, and extract the current file-locked download UI for reuse by both layouts without changing table behavior.

**Tech Stack:** Payload CMS 3.85.2, Next.js 16 App Router, React 19, Radix Tabs, Tailwind CSS 4 semantic tokens, shadcn Button/Card/Table primitives, Vitest, Testing Library.

## Global Constraints

- `table` remains the saved default and runtime fallback; existing documents require no migration.
- Programme Cost Atlas uses the same fee categories, columns, rows, notes, tabs, appearance, and uploaded file as the table layout.
- Never calculate totals, parse financial values, convert currencies, combine equal values, or infer missing content.
- The first normalized `total` row supplies Annual totals; later `total` rows remain visible on the right.
- The desktop Atlas is an exact 50/50 split; mobile stacks left before right and keeps every value visible.
- Use semantic theme tokens only; add no raw SNMIH-specific colors.
- Do not add dependencies, routes, collections, globals, or registry abstractions.
- Preserve unrelated user changes in the dirty worktree.
- Do not stage, unstage, or commit any files.

```ts
import type {
  FeeStructureCategoryValue,
  FeeStructureProgrammeDetailValue,
  ResolvedFeeStructureCategory,
  ResolvedFeeStructureProgrammeDetail,
} from './types'

export function normalizeProgrammeDetails(
  details?: FeeStructureProgrammeDetailValue[] | null,
): ResolvedFeeStructureProgrammeDetail[] {
  return (details ?? []).flatMap((detail, index) => {
    const label = normalizeText(detail.label)
    const value = normalizeText(detail.value)
    return label && value ? [{ id: `${detail.id ?? 'detail'}-${index}`, label, value }] : []
  })
}
```

Move the existing FileText/Download/Button/link markup and variant resolver unchanged into `FeeStructureDownload.tsx`:

```tsx
import { Download, FileText } from 'lucide-react'

import { resolveBlockAppearanceClasses } from '@/blocks/shared/blockAppearance'
import { Button, buttonVariants } from '@/components/ui/button'
import type { CmsActionVariant } from '@/lib/cmsLinks'
import { cn } from '@/lib/utils'

import type {
  FeeStructureDownloadButtonVariant,
  ResolvedFeeStructureDownload,
} from './types'

const variants = new Set<CmsActionVariant>([
  'default', 'primary', 'secondary', 'outline', 'white', 'whiteOutline',
])

export const resolveDownloadButtonVariant = (
  value?: FeeStructureDownloadButtonVariant | null,
): FeeStructureDownloadButtonVariant =>
  variants.has(value as CmsActionVariant) ? (value as FeeStructureDownloadButtonVariant) : 'outline'

export function FeeStructureDownload({ download }: { download: ResolvedFeeStructureDownload }) {
  const appearance = resolveBlockAppearanceClasses(download.appearance)
  const surface = appearance.background === 'none' ? download.sectionBackground : appearance.surface

  return (
    <div
      className={cn(
        'flex flex-col gap-4 rounded-[var(--radius)] border border-current/15 p-5 sm:flex-row sm:items-center sm:justify-between',
        appearance.className,
      )}
      data-fee-document="true"
      data-fee-download-background={appearance.background}
    >
      <div className="flex items-center gap-3">
        <FileText aria-hidden="true" className="size-5" />
        <p className="font-semibold">Official fee structure</p>
      </div>
      {download.mode === 'link' ? (
        <a
          className={cn(
            buttonVariants({ variant: 'link' }),
            'group/button h-auto gap-2 px-0 py-0 text-sm font-semibold text-current no-underline hover:text-current/80 hover:no-underline',
          )}
          data-fee-download-mode="link"
          download
          href={download.url}
        >
          <span className="underline decoration-current decoration-2 underline-offset-4">
            {download.label}
          </span>
          <Download aria-hidden="true" data-icon="inline-end" />
        </a>
      ) : (
        <Button
          asChild
          className={cn(
            surface === 'brand' && download.buttonVariant === 'outline' &&
              'border-current/70 text-current hover:border-current hover:bg-current/10',
          )}
          variant={download.buttonVariant}
        >
          <a data-fee-download-mode="button" download href={download.url}>
            <Download aria-hidden="true" data-icon="inline-start" />
            {download.label}
          </a>
        </Button>
      )}
    </div>
  )
}
```
